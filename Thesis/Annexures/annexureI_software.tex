\subsection{Hardware Platform}
\label{annexure:hardware}

\begin{itemize}
    \item Processor: Apple Silicon (M-series)
    \item Primary compute device: MPS via PyTorch
    \item SHAP compute device: CPU (faster than MPS for GradientExplainer)
    \item Fallback: CPU (used when MPS is unavailable or for SHAP computations)
\end{itemize}

The PyTorch device was selected automatically: MPS if available on Apple Silicon, CUDA if available on NVIDIA hardware, and CPU as fallback.

\subsection{Reproducibility}
\label{annexure:reproducibility}

Fixed random seed of 42:
\begin{itemize}
    \item PyTorch weight initialisation (\texttt{torch.manual\_\allowbreak{}seed(42)})
    \item NumPy random operations (\texttt{np.random.seed(42)})
    \item NumPy Generator objects (\texttt{np.random.default\_\allowbreak{}rng(42)})
    \item scikit-learn train/test split (\texttt{random\_state=42})
    \item RF fitting (\texttt{random\_state=42})
    \item XGBoost fitting (\texttt{seed=42})
    \item GP surrogate fitting (\texttt{random\_state=42})
\end{itemize}

% -------------------------------------------------------------
\subsection{Data Files}
\label{annexure:data_files}

\begin{itemize}
    \item \texttt{insurance\_\allowbreak{}dataset.csv}: 1\,000\,000 rows, 12 columns (age, gender, bmi, children, smoker, region, medical\_history, family\_medical\_history, exercise\_frequency, occupation, coverage\_level, charges). Benchmark dataset sourced from Kaggle \citep{kaggleInsuranceDataML}.

    \item \texttt{chapter3\_final\_\allowbreak{}model.pth}: PyTorch checkpoint containing the trained FunnelDNN model state, architecture specification, hyperparameters, standardisation parameters, feature names and evaluation metrics.

    \item \texttt{model\_ready\_charges\_\allowbreak{}train\_\allowbreak{}20260517\_115748.csv}: reference-category encoded training partition (60\% of the dataset, 22 features + charges).
\end{itemize}

\subsection{Code Availability}
\label{annexure:code_availability}

The Python code used for data preprocessing, model training, MC simulation, GLM and tree-based benchmarking, Shapley-value computation and diagnostic figure generation is available as supplementary material. The code is organised into separate Jupyter notebooks corresponding to each stage of the analysis:

\begin{itemize}
    \item Data preprocessing and reference-category encoding (\ref{annexure:preprocessing}).
    \item DNN architecture definition and training (\ref{annexure:dnn_training}).
    \item Parametric MC simulation (\ref{annexure:mc_simulation}).
    \item GLM benchmark fitting and comparison (\ref{annexure:glm_benchmark}).
    \item Tree-based benchmark fitting: RF and XGBoost (Section~\ref{sec:tree_benchmarks_methods}).
    \item Shapley-value computation and conditional analysis (\ref{annexure:shapley}).
\end{itemize}

Package versions and computing environment details are reported in \ref{annexure:packages} to \ref{annexure:reproducibility} above. Full source code is available from the author on request.
