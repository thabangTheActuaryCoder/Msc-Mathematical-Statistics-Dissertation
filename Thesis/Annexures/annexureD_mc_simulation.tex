\section{MC Simulation Procedure}
\label{annexure:mc_simulation}

The parametric \gls{mc} simulation generates $B = 100\,000$ synthetic policyholder profiles from marginal distributions estimated from the training partition only, in accordance with the leakage-prevention protocol of Section~\ref{sec:mc_simulation_design}. Each profile is encoded, standardised and scored through the trained FunnelDNN to produce a model-implied predicted-cost distribution.

\subsection{Profile Generation and Scoring}
\label{annexure:mc_generate}

The simulation procedure itself is specified in Section~\ref{sec:mc_simulation_design} and is not restated here. Algorithm~\ref{alg:mc_simulation} records only the concrete run configuration used in this study: the random seed, the sample size and the encoded input dimension.

\begin{algorithm}[htbp]
\caption{Parametric \gls{mc} simulation.}
\label{alg:mc_simulation}
\begin{algorithmic}[1]
\Require Fitted marginals, trained \gls{dnn} $f_{\boldsymbol{\theta}^*}$, standardisation parameters, sample size $B = 100\,000$
\Ensure Predicted-cost vector $\hat{\mathbf{y}}_{\mathrm{MC}} \in \mathbb{R}^B$
\State Initialise random number generator with seed 42
\For{$i = 1, \ldots, B$}
    \State Sample each variable independently from its marginal distribution
    \State Apply reference-category encoding to obtain $\mathbf{x}_i \in \mathbb{R}^{22}$
\EndFor
\State Standardise: $\mathbf{X}_{\mathrm{MC}} \gets (\mathbf{X}_{\mathrm{MC}}^{\mathrm{raw}} - \boldsymbol{\mu}_X) / \boldsymbol{\sigma}_X$
\State Forward pass: $\hat{\mathbf{y}}_{\mathrm{norm}} \gets f_{\boldsymbol{\theta}^*}(\mathbf{X}_{\mathrm{MC}})$
\State De-normalise: $\hat{\mathbf{y}}_{\mathrm{MC}} \gets \hat{\mathbf{y}}_{\mathrm{norm}} \cdot \sigma_y + \mu_y$
\end{algorithmic}
\end{algorithm}

\subsection{Convergence Diagnostics}
\label{annexure:mc_convergence}

\gls{mc} convergence was assessed using the pilot procedure described in Section~\ref{sec:mc_simulation_design}, in which the running mean, standard deviation, selected quantiles and \gls{mcse} are recomputed at increasing pilot sample sizes; the pilot grid is listed in that section and is not repeated here. Stabilisation of the mean and tail quantiles confirmed that $B = 100\,000$ provides adequate precision.

% -------------------------------------------------------------
\subsection{Residual-Augmented Sensitivity}
\label{annexure:mc_residual}

Sensitivity of the predicted-cost distribution to model uncertainty was assessed by augmenting point predictions with resampled centred training residuals:
\[
  \hat{y}_i^{\mathrm{aug}} = \hat{y}_i + \varepsilon_i,
\]
where $\varepsilon_i$ is drawn with replacement from the centred residual vector. Fixed perturbation bands of $\pm 0.5\,\hat{\sigma}_\varepsilon$ were also computed.

% -------------------------------------------------------------
\subsection{Encoding for MC Profiles}
\label{annexure:mc_encode}

The same reference-category encoding scheme described in \ref{annexure:encoding} was applied to the \gls{mc} profiles, producing an $B \times 22$ feature matrix that matches the trained model's input specification.

% -------------------------------------------------------------
\subsection{DNN Scoring}
\label{annexure:mc_score}

Each encoded profile is standardised using the training-set parameters ($\boldsymbol{\mu}_X$, $\boldsymbol{\sigma}_X$), passed through the trained \gls{dnn} in a single forward pass (with gradients disabled), and de-normalised to the original Rand scale using the training-set response parameters ($\mu_y$, $\sigma_y$).
