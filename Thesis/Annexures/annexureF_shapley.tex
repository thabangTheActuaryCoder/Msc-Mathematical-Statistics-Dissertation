\section{Shapley-Value Computation Procedure}
\label{annexure:shapley}

Approximate Shapley values were computed using the SHAP library's GradientExplainer, which uses integrated gradients as an approximation to exact Shapley values for differentiable models. All SHAP computations were performed on CPU, as GradientExplainer runs faster on CPU than on MPS for this model size.

% -------------------------------------------------------------
\subsection{Computation Procedure}
\label{annexure:shap_setup}

\begin{algorithm}[htbp]
\caption{Batch Shapley-value computation with dummy-to-raw aggregation.}
\label{alg:shap_computation}
\begin{algorithmic}[1]
\Require Trained DNN $f_{\boldsymbol{\theta}^*}$ (CPU copy), standardised training data $\mathbf{X}_{\mathrm{train}}$, standardised MC profiles $\mathbf{X}_{\mathrm{MC}}$, batch size $B_s = 2\,000$
\Ensure Raw-variable Shapley matrix $\boldsymbol{\Phi} \in \mathbb{R}^{B \times 11}$
\State Sample 200 background rows from $\mathbf{X}_{\mathrm{train}}$ (seed 42)
\State Initialise GradientExplainer with $f_{\boldsymbol{\theta}^*}$ and background data
\For{each batch of $B_s$ foreground profiles}
    \State Compute Shapley values $\boldsymbol{\phi} \in \mathbb{R}^{B_s \times 22}$
\EndFor
\State Concatenate batches to obtain $\boldsymbol{\Phi}_{22} \in \mathbb{R}^{B \times 22}$
\For{each raw variable $j = 1, \ldots, 11$}
    \State $\boldsymbol{\Phi}_{:,j} \gets \sum_{k \in \mathcal{C}_j} \boldsymbol{\Phi}_{22_{:,k}}$ \Comment{Sum over dummy columns $\mathcal{C}_j$}
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Efficiency Verification}
\label{annexure:shap_efficiency}

The Shapley efficiency axiom $\bigl(\sum_{j=1}^{p} \phi_j = f(\mathbf{x}) - \phi_0\bigr)$ was verified for all $B$ profiles. The maximum absolute reconstruction error was below 0.5 normalised units, confirming that the gradient-based approximation satisfies the efficiency property to adequate precision.

% -------------------------------------------------------------
\subsection{Global Importance}
\label{annexure:shap_global}

Global feature importance was computed as the mean absolute Shapley value across all $B$ Monte Carlo profiles: $\bar{|\phi|}_j = B^{-1} \sum_{i=1}^{B} |\phi_{ij}|$ for each raw variable $j$. Variables were ranked by this measure to identify the most influential predictors of insurance cost.

% -------------------------------------------------------------
\subsection{High-Cost Conditional Shapley Analysis}
\label{annexure:shap_conditional}

High-cost conditional Shapley analysis was performed by subsetting the Shapley matrix to profiles with predicted costs exceeding the $\tau_{90}$, $\tau_{95}$ and $\tau_{99}$ quantiles of the MC distribution. Global and conditional importance rankings were compared to identify features whose influence shifts in the tail of the cost distribution.
